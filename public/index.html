Wall Settings

Messages — each line of a message is sent as its own chat message, 1.5s apart, so you can pair a public call-out with a private status line. Placeholders: {minutes} unchecked, {player} who checked last, {checks} that player's count, {total} checks all-time.

Discord embed body — Discord posts arrive as an embed with a coloured bar, a title and a timestamp. This field is the body of the reminder embed and supports markdown (**bold**), so it can be richer than the in-game line. Raid alerts reuse their own chat text as the body.

Checks to a logs channel — every recorded check posts a log embed: the player's head and name, when the walls were confirmed clear, how long since the previous check, and their raid/wall check counts. A check logged while a raid alert is running counts as a raid check instead of a wall check. Leave the toggle off and these follow the wall bot's Discord settings; leave the URL blank and they fall back there too. The player head is fetched by Discord from mc-heads.net.

Listen on — dm (default) counts a trigger only when a player messages the bot privately, so a stray word in public chat can't fire it. chat reads public and faction chat instead. Anything else is treated as a custom /regex/ capturing the player name then the message.

Raid alerts

Triggers accept a comma-separated word list, matched on whole words, or a /regex/ literal. Messages are sent exactly as written — start them with /f c to scope them to faction chat.

While a raid alert is running, wall reminders stop and resume when it's turned off. The Discord alert repeats on the interval below with a TNT icon, the raid headline, and a running time since alert; clearing it posts how long the alert lasted. Reminders also pause during quiet hours.

Raid webhook — leave the toggle off and raid alerts follow the wall bot's Discord settings above. Turn it on with a URL set, and raids go to that channel instead, so alarms can live somewhere noisier than routine wall checks. If the toggle is on but the URL is blank, raids fall back to the wall webhook rather than going nowhere.

Quiet hours — reminders stop, and in-game checks are refused with a note rather than counted. When the window lifts, the unchecked count restarts from zero, so the first message of the day isn't a number covering the whole night. The panel's Mark checked button still works as an operator override, and raid alerts are never gated — a raid is an emergency whenever it lands.

Quiet hours use the panel server's clock, not yours. A VPS usually runs on UTC — set TZ=America/New_York (or your zone) in .env and restart to make these times local.
